# 🗓️ MCA TimeTable

A clean and responsive timetable dashboard for MCA Semester 1 students to quickly view their class schedule by division and batch.

[Live Demo](https://reven-99.github.io/McaTimeTable/)

## ✨ Highlights

- Smart timetable filtering by division and batch
- Day-wise and week-wise schedule views
- Real-time clock and current class indicator
- Theme toggle for light/dark mode
- Optimized for desktop and mobile screens
- Easy selection for theory and practical batches

## 🧭 What this project does

This web app helps students track:

- Theory classes
- Practical lab sessions
- Free periods
- Current class status
- Upcoming timetable entries

It is designed specifically for the MCA Sem 1 schedule and supports the division/batch combinations available in the timetable.

## 📚 Supported options

- Divisions: A, B, C
- Theory batches: A1, A2, B1, B2, C1, C2
- Practical batch selection based on the chosen division

## 🚀 How to use

1. Open the live app or run the project locally.
2. Select your theory division.
3. Choose your practical batch.
4. View the schedule in either:
   - Day view
   - Week view
5. Use the theme button to switch between light and dark mode.
